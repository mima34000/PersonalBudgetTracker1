//Personal Budget Tracker//

// Description
This is a simple console application written in C# that helps users track their incomes and expenses.
The program allows users to add transactions, view all transactions, see the total balance, and delete transactions.

// Features
- Add income and expense transactions
- View all transactions
- Calculate total balance
- Delete transactions
- Color-coded output (green for income, red for expenses)

// Technologies
- C#
- .NET Console Application
- Git & GitHub

// How to run the program
1. Open the project in Visual Studio
2. Click the green Run button ▶️
3. Follow the instructions in the console menu
